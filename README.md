# 商品ポップメーカー

商品名・説明文・価格を入力するだけで、店頭で使える商品ポップ（POP）を作って印刷できる Web ツールです。
インストールもアカウント登録も不要。`index.html` をブラウザで開くだけで動きます。

![商品ポップメーカーの画面。上段に保存済みデザインの棚、左にポップ一覧、中央に編集パネル、右にプレビューと印刷の確認バー](docs/screenshot.png)

## 画面の構成

上から4層。よく使うものほど上・左に置いています。

```
┌──────────────────────────────────────────────────────┐
│ ヘッダー：タイトル／1 保存済みから選ぶ → 2 文字を入れる → 3 印刷する │
│           ／その他 ▾／画像で保存／印刷する                      │
├──────────────────────────────────────────────────────┤
│ 「その他 ▾」を押したときだけ出るバー                            │
│  データの書き出し・読み込み／解像度／全ページ保存／すべてリセット      │
├──────────────────────────────────────────────────────┤
│ 保存済みデザインの棚（クリックで今のポップに見た目を当てる）           │
├───────────┬──────────────────┬─────────────────────┤
│ ポップ一覧   │ 編集パネル（2タブ）  │ プレビュー ＋ 印刷の確認バー │
└───────────┴──────────────────┴─────────────────────┘
```

編集パネルは2つのタブに分かれています。

| タブ | 中身 |
| --- | --- |
| **文字を入れる**（既定） | 商品名・価格・キャッチコピー・説明文・注記。細かい表記（通貨記号・単位・バッジ）は折りたたみの中 |
| **デザインを作る** | テンプレート9種／文字（フォント・サイズ・色）／配置・枠線・背景色／ポップの大きさ・印刷する紙／画像 |

プレビューは「**ポップ1枚**」と「**印刷される紙**」をワンタッチで切り替えられます。

## できること

### 複数のポップをまとめて作る・まとめて印刷する
- **ポップ一覧**で、内容の違うポップを1つのファイルにまとめて作れます（最大100枚）
- **ポップの大きさは任意の mm**（既定 44×67mm）。プリセット（名刺・A7・A8・B8・正方形）も選べます
- 印刷すると**紙へ自動で面付け**され、余白が最小になるように並びます
  （A4・安全余白5mm なら 44×67mm が **16枚**、余白0mm なら 90°回転して **18枚**）
- 入り切らない分は**自動で次のページ**になり、1回の印刷ダイアログでまとめて刷れます
- ポップ同士の境界に**カット線**が入るので切り分けやすくなっています
- プレビューの下に「**A4 縦 1枚に16枚ぶん並びます（3枚を印刷 → 1ページ）**」と出るので、刷る前に枚数とページ数が分かります
- 「**複製して続ける**」で、いま入れた文字を残したまま次のポップへ進めます

### 入力できる情報
| 項目 | 内容 |
| --- | --- |
| 商品名（必須） | 複数行OK。長い名前は自動で折り返します |
| 価格（必須） | 3桁カンマ区切り、通貨記号（¥）、単位（円）、税表記（税込／税抜など） |
| 商品の説明文 | 複数行OK |
| キャッチコピー | 「本日のおすすめ」など、商品名の上に入る一言 |
| 通常価格 | 打ち消し線つきで併記（セール表示用）。チェックを入れたときだけ入力欄が出ます |
| 補足 | 「/ 100g」などの単価表記 |
| 注記・店名 | 「※数量限定」などの小さい文字 |
| バッジ | NEW・おすすめ などのタグ（角丸タグ／リボン／丸印）。チェックを入れたときだけ入力欄が出ます |

### 文字の調整
- **項目ごと**に フォント・文字サイズ（pt）・太さ（標準／太字／極太）・文字色・行間 を設定
- 日本語フォント23種（お使いのPCのゴシック体・明朝体・丸ゴシック体＋Google Fonts の日本語フォント20種）
- フォントは系統別（ゴシック体／明朝体／丸ゴシック／手書き／筆・和レトロ／かわいい・ポップ）に分かれています
- 手書き系4種（Yusei Magic・Zen Kurenaido・Klee One・Yomogi）、筆・和レトロ系5種（Yuji Syuku ほか）、かわいい・ポップ系3種（Hachi Maru Pop ほか）
- 「このフォントを他の項目にも適用」で一括統一
- 「すべて小さく／大きく」で全体のバランスを保ったままサイズ変更
- **自動縮小**：用紙からはみ出すときは、収まる最大サイズを自動計算

### 商品画像・ロゴ
- 画像を取り込んでポップに配置（**プレビュー上でドラッグ移動・四隅で拡大縮小**）
- 文字の**前面／背面**を切替（写真の上に文字を重ねる／写真を主役に文字を上へ）、透明度・幅(mm)調整
- 取り込み時に自動で軽量化（長辺800〜2000px。カードの大きさに連動、小さいカードほど軽く）。PNG／印刷にもそのまま反映

### レイアウト・デザイン
- 印刷する紙：**JIS A判（A3〜A8）／JIS B判（B4〜B8）** ＋ はがき／名刺／正方形／短冊／カスタム（mm指定）、縦横切替（B判はJIS寸法。ISO Bとは別）
- 安全余白（既定5mm）・ポップの間隔・90°自動回転・中央寄せ・カット線を設定できます
- 「ポップの大きさ」と「印刷する紙」は1つの折りたたみにまとめてあります（両方を見ないと面付けが決まらないため）
- 文字揃え（左・中央・右）、縦の配置（上寄せ・中央・上下いっぱい）、余白、要素の間隔、区切り線
- テンプレート9種：シンプル／セール／ポップ／ナチュラル／手書き風／かわいい／和風／レトロ／ダーク
- 背景色・アクセント色・枠線（実線／二重線／破線／角丸）・ヘッダー帯
- 「この見た目をすべてのポップに適用」で、いま編集中のポップの見た目（フォント・色・テンプレートなど）を他のポップにも一括で反映（商品名・価格・画像は変わりません）

### 保存済みデザイン（画面上段の棚）
- 「**＋ 今の見た目を保存**」で、いまのポップの見た目に名前を付けて棚に置けます（最大30件）
- 棚のデザインをクリックすると、**選択中のポップに見た目だけを当てます**。商品名・価格・説明・画像は**そのまま残ります**
- 保存されるのはテンプレート・色・フォント・枠線・配置と**ポップの大きさ**。文章は含みません
- 「お菓子コーナー用のデザインを呼び出して、文字だけ差し替える」という使い方をひと手で行えます

### 出力・保存
- **画像で保存**（150 / 300 / 600 dpi）— 300dpi なら印刷しても文字がにじみません。「印刷される紙（面付け済み）」「選択中のポップのみ」を選べ、紙は全ページ一括保存にも対応（範囲と解像度の設定は「その他 ▾」の中）
- **印刷する** — 面付けされた紙を、用紙サイズに合わせた原寸で1回の印刷ダイアログにまとめて出します。押すとプレビューが「印刷される紙」に切り替わり、刷られる状態が見えます
- **データを書き出す／読み込む** — 設定を JSON ファイルで持ち出し・共有（「その他 ▾」の中）
- 編集内容は自動保存され、次に開いたときに復元されます（保存の状態はヘッダー右に出ます）

## 使い方

### そのまま使う
1. このリポジトリをダウンロード（または `git clone`）
2. `index.html` をダブルクリックしてブラウザで開く
3. 「文字を入れる」タブで商品名と価格を入力 →「デザインを作る」タブで見た目を整える → 右のプレビューを確認して「印刷する」または「画像で保存」
4. よく使う見た目は「＋ 今の見た目を保存」で棚に置いておくと、次回は棚から呼び出して文字を差し替えるだけで済みます

> Google Fonts の日本語フォント（Noto Sans JP、Zen Kurenaido など）を使う場合はインターネット接続が必要です。
> フォントは**選んだときに初めて読み込まれる**ので、起動は軽いままです。
> オフラインのときは自動的にお使いのパソコンのフォントで表示されます（レイアウトは崩れません）。

### GitHub Pages で公開する
リポジトリの Settings → Pages で、Source に `main` ブランチのルート（`/`）を指定するだけです。
ビルド作業は必要ありません。

### 印刷のコツ
- プリンタの設定で「拡大縮小なし（実際のサイズ / 100%）」「余白なし」を選ぶと、指定した用紙サイズどおりに刷れます
- 「PNG保存」した画像をコンビニのネットプリントに登録して印刷することもできます
- 家庭用プリンタは用紙の端 5mm 前後が印字できません。既定の「安全余白 5mm」のままなら端のカードが欠けません
- 余白 0mm は枚数が増えますが、フチなし印刷に対応したプリンタでのみお使いください

## ファイル構成

```

assets/css/style.css    操作画面のスタイル
design_handoff_pop_maker_ui/   UI再設計の引き継ぎ仕様（実装の元になったデザイン）
assets/js/
  fonts.js              フォント定義とWebフォントの読み込み
  text.js               日本語の折り返し（禁則処理）・数値の3桁区切り
  presets.js            ポップの大きさ・用紙・テンプレート・比例スケール
  imposition.js         面付け計算（何列何段・回転の要否・ページ数）
  renderer.js           ポップ1枚の描画エンジン（プレビューと書き出しで共通）
  sheet-view.js         面付けされた紙の合成描画
  doc.js                ポップ集の操作・見た目だけの抽出/適用・旧データの移行
  storage.js            自動保存・保存済みデザイン・ファイル入出力
  image-tool.js         商品画像の操作（ドラッグ・リサイズ・取り込み）
  preset-ui.js          保存済みデザインの棚
  export-tool.js        出力（面付けした紙の印刷・画像保存）
  cards-ui.js           ポップ一覧の表示と操作
  app.js                画面の組み立てとイベント処理
```

## 技術的なメモ

- **依存ライブラリなし**（素の HTML / CSS / JavaScript）。ビルド不要で `file://` からも動くよう、ES Modules ではなく通常の `<script>` で読み込んでいます
- **プレビューと書き出しは同じ描画関数**（`renderer.js`）を使い、`pxPerMm` を変えるだけで解像度を切り替えます。そのため画面で見たとおりの結果が印刷されます
- **禁則処理を自前実装**：行頭に `、。」` などが来ない／行末に `「（` などが来ないように折り返します（`text.js`）
- **自動縮小は二分探索**：文字を縮めると折り返し行数も変わるため、比例計算ではなく「用紙に収まる最大の倍率」を探索しています
- 保存は `localStorage`。プライベートブラウジングなどで使えない場合は、その旨を画面に表示します
- **保存済みデザインは「見た目だけ」を切り出して保存**します（`POPDoc.designOf`）。文章と画像を持たないので、棚のデザインを当てても入力中の文字は消えず、保存領域も膨らみません
- プレビューの大きさは `ResizeObserver` で追随します。窓の大きさだけでなく「その他 ▾」の開閉でも表示領域が変わるためです

## テスト

依存ライブラリなし・Node の組み込みモジュールだけで動く軽量テストを同梱しています。
折り返し・3桁区切り・`ptPx`・`mergeDeep`（null耐性・プロトタイプ汚染対策）・入力値クランプの回帰を検証します。
面付け計算・寸法解決・比例スケール・旧データ移行も検証します。
canvas 描画と印刷はブラウザでの目視確認になります。

```
node test/run.js   # または npm test
```

## アクセシビリティ

- 編集パネルのタブ（文字を入れる／デザインを作る）と文字設定の項目切替は、どちらも ARIA タブパターン対応（`←`/`→`/`Home`/`End` で移動）
- ポップ一覧は `↑`/`↓` で選択、`Alt`＋`↑`/`↓` で並べ替え（ドラッグでも可）
- プレビューには内容を要約した `aria-label` を付与
- 画像は数値（幅・位置X/Y mm）でも配置でき、ポインタが使えなくても操作できます

## 動作環境

Chrome / Edge / Firefox / Safari の最新版。
画面は **PC・ノートPC（幅1280px以上を想定）** 向けです。狭い画面では手順表示を省き、
940px 未満では3カラムを縦に積みます（スマートフォンでの利用は想定していません）。
