# 設計: 画像/ロゴ挿入 & JIS用紙サイズ拡充

- 日付: 2026-08-17
- 対象: 商品ポップメーカー（依存ライブラリなしの素の HTML/CSS/JS・canvas描画）
- 状態: 承認済み（実装中）

## 背景

既存ツールに、ユーザー要望の2機能を追加する。
1. 商品画像/ロゴの挿入（**写真を大きく**＋**自由に移動・拡大縮小**）
2. **JIS 用紙サイズの拡充**（既存の A4〜A7 / B5・B6 はすでに JIS 寸法。ラインナップを増やす）

設計原則は既存に踏襲：依存ライブラリなし・`file://`/静的配信で動作・プレビューと書き出しは同一描画関数（WYSIWYG）。

## 機能A: 画像/ロゴ挿入

### データモデル（`state.image`）
```
image: {
  src: '',        // dataURL（空 = 画像なし）
  xMm: 0, yMm: 0, // 用紙左上からの位置（mm）
  wMm: 0,         // 幅（mm）。高さ = wMm / aspect
  aspect: 1,      // naturalWidth / naturalHeight
  opacity: 1,     // 0.1〜1
  layer: 'back'   // 'back' = テキストの後ろ / 'front' = テキストの前
}
```

### 取り込み
- 「画像を追加」→ ファイル選択（`accept="image/*"`）。
- canvas で**長辺2000pxに自動縮小**して保存容量を抑制。透過PNG（ロゴ）は PNG のまま、それ以外は JPEG(q0.9) 化。
- 初期配置：用紙中央、幅 = 用紙幅の60%。`layer='back'`、`opacity=1`。

### 描画順（renderer.draw）
背景 → 画像(back) → 帯 → テキスト → 画像(front) → 枠線 → バッジ。
`draw(ctx, state, pxPerMm, assets)` に第4引数 `assets = { image: HTMLImageElement|null }` を追加。
`renderToCanvas(state, dpi, assets)` も同様に受け取り、PNG/印刷にも反映。ハンドルは**描かない**。

### 画像のロード（app.js）
フォント読込と同じ遅延ロード方式。`imgCache[src]` に読込済み `Image` を保持。
`render()` は現在キャッシュ済みの画像で一旦描画し、未ロードならロード後 `requestRender()`。

### プレビュー操作（“自由に移動・拡大縮小”）
- `POPRenderer.draw` の**後**に、app.js が選択枠＋四隅ハンドルをプレビュー canvas に重ね描き（**書き出しには出ない**）。
- Pointer Events（マウス＋タッチ）。canvas に `touch-action:none`。
- ヒットテスト（mm換算）：四隅ハンドル内 = アスペクト維持リサイズ（対角を固定）、画像内 = 移動。
- 最小幅 10mm でクランプ。

### パネルUI（新セクション「画像」）
- 画像を追加/差し替え・削除ボタン、`file-image`（hidden）
- 幅(mm)・透明度・前面/背面（`data-path` バインドで既存機構に載せる）
- 画像が無い間はコントロールを隠す（`custom-size` と同じ hidden トグル）
- 「プレビュー上でドラッグ＝移動／四隅＝拡大縮小」の説明文

### 保存
- `state.image` ごと JSON/自動保存に含む。
- 画像が大きく `localStorage` に入らない時：`saveAuto` は真偽を返し、失敗かつ画像ありなら**一度だけ**通知（「画像が大きく自動保存できません。『データ保存』で書き出せます」）。セッション中の表示は継続。
- PNG/印刷は現解像度で `drawImage` ＝高dpiでも綺麗。

## 機能B: JIS用紙サイズ拡充

### 追加サイズ（mm・縦向き）
- JIS A判: A3(297×420), A8(52×74) を追加（既存 A4〜A7）
- JIS B判: B4(257×364), B7(91×128), B8(64×91) を追加（既存 B5・B6）。B系は**JIS寸法**。

### 用紙選択の整理
`PAPERS` 各要素に `group` を付与し、`buildPaperOptions` を `<optgroup>` 対応に：
「JIS A判 / JIS B判 / その他定型（はがき・名刺・正方形・短冊）/ カスタム」。
B判ラベルに `・JIS` を併記して ISO B との誤解を防ぐ。
`paperSize` / `papersById` は現行のままで動作。

## リスク/トレードオフ
- 画像は長辺2000pxに縮小するため、超大判×高dpiでは写真精細感が上限。実用範囲では問題なし。
- 大きな画像は自動保存に入らない場合がある（上記の通り通知＋JSON保存で回避可能）。

## 検証
- JIS: 全 optgroup が出る／A3・B4・B7・B8 を選ぶと寸法メタが正しい。
- 画像: 追加→プレビュー表示、ドラッグ移動・四隅リサイズ、前面/背面、透明度、削除、PNG/印刷反映、JSON保存/読込で復元。
- 回帰: 既存6テンプレの重なりなし（価格ブロック修正済み）を維持。
